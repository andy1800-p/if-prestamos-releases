# Impulso Financiero 1.0.0+1

Primera versión de Impulso Financiero para Android.

- Acceso con Google conectado al proyecto Firebase IF Prestamos.
- Registro y consulta de préstamos y abonos.
- Calendario de pagos e historial por préstamo.
- Comprobantes digitales e impresión desde Android.
- Nombre e icono de Impulso Financiero.
